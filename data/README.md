# Dataset

Place the original dataset here with the exact filename:

```text
ev_charging_patterns.csv
```

The analysis requires at least these two columns:

- `Energy Consumed (kWh)`
- `Charging Duration (hours)`

The CSV is intentionally not included in this package because its original
source and redistribution license were not available when the portfolio
repository was prepared.

Before publishing the dataset on GitHub, verify that its license permits
redistribution. If redistribution is not permitted, keep the CSV locally and
document the public source in the main README instead.
